# Vina Georgiana — Personal Academic Website

A responsive, single-page academic profile with a warm, minimalist vintage editorial style.

## Publish with GitHub Pages

The website source is `index.html` on the `main` branch.

1. Open **Settings → Pages** for this repository:
   https://github.com/georgianavina-art/vg.github.io/settings/pages
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Set the branch to **main** and the folder to **/(root)**, then click **Save**.
4. Wait for GitHub Pages to finish deploying. GitHub notes publication can take several minutes.

Expected project-site address:
https://georgianavina-art.github.io/vg.github.io/

## Update the profile

Edit `index.html` to revise biography text, work history, research links, or contact links. The portrait area is currently a placeholder because no personal portrait was provided.
